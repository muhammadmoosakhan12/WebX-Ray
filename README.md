# 🔍 WebX-Ray — Next-Gen Website Intelligence & Audit Platform

**WebX-Ray** is a premium, developer-grade website auditing and intelligence platform designed for web developers, small business owners, agencies, and founders. It performs safe, real-time technical inspections on any web URL and delivers evidence-based analysis, security & metadata checks, accessibility reports, and AI-powered actionable fixes.

---

## ✨ Features

- 🎯 **Real-Time Technical Auditing:** Inspects HTML metadata, title tags, canonical URLs, headings hierarchy, viewport setups, image alt attributes, and open graph tags.
- 🤖 **AI-Powered Explanations:** Integrates Google's Gemini AI to analyze raw audit data and deliver human-friendly summaries, prioritized fixes, and optimized copy suggestions.
- 🛡️ **SSRF & Security Defense:** Server-side normalized URL validation protecting against internal network loops, invalid schemes, and malicious redirects.
- 📊 **Detailed Insights:** Categorized findings covering SEO, Accessibility, Page Structure, Mobile Readiness, and Usability.
- 💾 **Report History & Management:** Save, manage, export, and review previous audit reports.
- 🎨 **Editorial Dark SaaS UI:** Designed with a deep midnight-navy design system (`#080B14`), subtle violet accents, responsive typography, and clean iconography.

---

## 🛠️ Tech Stack & Architecture

- **Frontend & UI:** React, TypeScript, Tailwind CSS, Lucide Icons
- **AI Core:** Google Gemini API (for intelligent findings, fixes, and prioritization)
- **Backend / Safe Proxy:** Node.js / Serverless API routes for SSRF-safe website inspection
- **State & Storage:** LocalStorage / Supabase integration for persistence
